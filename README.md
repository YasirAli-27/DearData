# Dear Data 100 – Cars in London

## Project Overview
This project is part of the Dear Data 100 assignment. I am collecting data about cars commonly seen in London.

## Data Collection
I am recording 100 car observations. Each observation includes:

- **Number:** The observation number
- **Date:** The date the car was spotted
- **Make:** The manufacturer of the car
- **Model:** The model of the car
- **Colour:** The colour of the car
- **Vehicle Type:** The body type, such as hatchback, saloon, SUV, estate or coupe

## Dataset
The collected observations are stored in `cars.csv`.

## Progress
My target is to collect 100 car observations. I am currently working towards completing the dataset.

## Purpose
The aim of this project is to collect and organise data that can later be used to create a visual representation of the different cars seen in London.
